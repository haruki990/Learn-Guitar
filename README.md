# Phím Đàn – app học guitar

Web app tĩnh (một file `index.html`, không cần cài đặt hay build).

## Chạy trên máy
Mở `index.html` bằng trình duyệt (Chrome, Edge, Firefox).

## Tính năng
- **Nhạc lý:** 12 nốt, cần đàn + âm giai, dựng hợp âm, hợp âm trong giọng, vòng hợp âm.
- **Hợp âm:** sơ đồ thế bấm cho 8 loại hợp âm × 12 gốc.
- **Bài mẫu:** bài phạm vi công cộng, điệu quạt, đổi tông, gợi ý capo.
- **Đọc sheet:** MusicXML (.musicxml/.xml/.mxl) hoặc giai điệu gõ tay → đoán giọng, hợp âm từng ô nhịp, capo.

## Đưa lên web miễn phí
- **GitHub Pages:** đẩy thư mục này lên một repo GitHub, vào Settings → Pages → Deploy from branch `main` / root.
- **Netlify Drop:** vào https://app.netlify.com/drop, kéo thả thư mục này vào trang.
